From inbox to working draft

  1. Drop in your notes

    Use Markdown, text, or JSON files in a local workspace inbox.

  2. Run one pass

    Eligible work produces a draft and evidence you can inspect. In offline mode the draft assembles source excerpts.

  3. Review a held source

    If wording such as “deploy” matches a configured term, inspect the held item and decide whether it can enter drafting.

Approved for local drafting

A signed approval makes the source eligible for a later draft. Looping Box prints the next command for that workspace. Sending, publishing, and deploying stay in your own workflow.
