Product overview

Traceable drafts from local files

Make a draft.
Keep the trail.

Looping Box is a command-line tool for one operator. Run a pass on a folder of text files and get a working draft you can trace back to its sources.

How a pass works

Drop in local files
Put Markdown, text, or JSON files in the workspace inbox.
Read the draft
The default offline pass assembles short excerpts. Find source paths in the Markdown and provenance in the adjacent JSON.
Decide on held items
Configured wording such as “deploy” can hold a source. Signed approval makes it eligible for local drafting only. The CLI prints the next command.

Try 50 runnable examples

Run an example offline or add --free to send eligible sample excerpts to OpenRouter’s free router for the first draft.

Use python3.14 demos/examples.py --runs to review local run records, with draft snapshots, models, and reported costs when available.
